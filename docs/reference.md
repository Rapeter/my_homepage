# 当前实现：Zach Holman 首页布局复刻

用户最新要求取代先前的卡片式主页及数字分身需求：先复刻参考页，功能以后再加。

参考：[https://zachholman.com/](https://zachholman.com/)，2026-10-09 实际浏览器核对。

## 对齐的样式

- 背景 `#f0f9ff`，系统无衬线字体。
- 桌面最大宽度 1600px，主内容占 4/5，侧栏占 1/5。
- 1440px 下，介绍横幅距左侧及顶部各 48px，宽 1056px、高 320px，8px 圆角；渐变从 `#312e81` 经 `#581c87` 到 `#be185d`。
- 横幅文字右对齐，24px / 32px，关键词采用紫色底的行内链接。
- 文章列表左右各留 64px，年份、日期和标题按参考排列；标题 14px，行间距 16px。
- 侧栏 12px 字体，顶部 48px，简介段落间距 20px，随后是个人介绍、社交与订阅、带左边线的说明。
- 小于 1024px 时，横幅 16px 外边距、高度至少 192px，资料侧栏排列到文章列表之后。

## 内容与边界

仅使用已提供的身份、近况、关注方向及兴趣；两篇简短内容于本次整理，不伪造往年文章、已完成项目或履历。没有使用 Zach 的个人文字、照片、社交账号或推广信息；侧栏对应位置替换为 Zhong 的资料和 GitHub。

保留首页、文章阅读、关于我、GitHub 和 Atom 订阅。旧聊天 HTML、JavaScript、问答逻辑、测试和头像已删除；构建会清理旧产物。旧版本保留在 Git 历史中。

参考页面中的人像与纹理属于对方的个人素材；本次复刻横幅底色及文字布局，没有填入他人的照片。当前资料没有真实头像照片。

## 验证结果

- `npm test`：构建清理回归测试通过；修改前已确认旧聊天文件会残留，修改后已移除。
- 源码预览和 `dist/` 预览均通过实际 Edge 浏览器检查。
- 1440px 下的横幅实测为 `(48, 48, 1056, 320)`，侧栏起点 `(1168, 48)`，年份起点 `(64, 416)`，与参考页一致。
- 320、360、390、768、1024、1440、1920px 无横向溢出；手机简介位于文章之后。
- 文章、个人介绍、返回列表、7 个本地文件与页面链接均可用；Atom XML 解析成功，含 2 条内容。
- 旧聊天资源及 Git 配置地址返回 404；无前端 JavaScript、输入框或按钮；控制台无错误；键盘跳转正文可用。
