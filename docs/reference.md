# 当前实现：Zach Holman 首页布局复刻

用户最新要求取代先前的卡片式主页及数字分身需求：先复刻参考页，功能以后再加。

参考：[首页](https://zachholman.com/)及 [About](https://zachholman.com/about)，2026-10-09 实际浏览器核对。

## 对齐的样式

- 背景 `#f0f9ff`，系统无衬线字体。
- 桌面最大宽度 1600px，主内容占 4/5，侧栏占 1/5。
- 1440px 下，介绍横幅距左侧及顶部各 48px，宽 1056px、高 320px，8px 圆角；渐变从 `#312e81` 经 `#581c87` 到 `#be185d`。
- 横幅文字右对齐，24px / 32px，关键词采用紫色底的行内链接。
- 文章列表左右各留 64px，年份、日期和标题按参考排列；标题 14px，行间距 16px。
- 侧栏 12px 字体，顶部 48px，简介段落间距 20px，随后是个人介绍、社交链接、带左边线的说明。
- 小于 1024px 时，横幅 16px 外边距、高度至少 192px，资料侧栏排列到文章列表之后。
- 用户头像位于横幅左侧，保留原始图片，使用 CSS 裁切和渐隐遮罩与渐变背景衔接。
- About 正文桌面最大宽度 808px、居中于主栏；开头为 30px 无衬线介绍，后续使用衬线正文，联系条置于正文下方。

## 内容与边界

仅使用已提供的身份、近况、关注方向及教育背景；两篇简短内容于本次整理，不伪造往年文章、已完成项目或履历。About 已删除爱好内容，新增“本科和研究生均毕业于墨尔本大学”，未补写未知的学位、专业或年份。没有使用 Zach 的个人文字、照片、社交账号或推广信息。

保留首页、文章阅读、关于我，以及用户确认的 Email、LinkedIn、X 和 GitHub。RSS 入口与 Atom 文件已删除。旧聊天 HTML、JavaScript、问答逻辑和测试已删除；构建会清理旧产物。旧版本保留在 Git 历史中。

头像使用用户提供的 `assets/avatar.jpg`；仅调整页面中的呈现方式，未修改原图像素。

## 验证结果

- `npm test`：构建清理回归测试通过，确保旧聊天文件和订阅文件不会残留在产物中；移除订阅前已确认相应测试失败。
- 源码预览和 `dist/` 预览均通过实际 Edge 浏览器检查。
- 1440px 下的横幅实测为 `(48, 48, 1056, 320)`，侧栏起点 `(1168, 48)`，年份起点 `(64, 416)`，与参考页一致。
- 首页及 About 在 320、360、390、768、1024、1440、1920px 无横向溢出；手机简介位于文章之后。
- 文章、个人介绍、返回列表、头像等 7 个本地文件与页面链接均可用；头像加载尺寸为 1080×1080，响应类型为 JPEG。
- About 教育内容、Email/LinkedIn/X 链接已核对；没有爱好内容或订阅入口。
- 旧聊天资源、Atom 文件及 Git 配置地址返回 404；无前端 JavaScript、输入框或按钮；控制台无错误；键盘跳转正文可用。
