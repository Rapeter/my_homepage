# Zhong 个人主页 V1

依据用户提供的需求文档制作，目标访客为朋友和面试官。交付可预览的响应式个人主页，并推送到用户指定仓库。

## 范围与取舍

- 原生 HTML、CSS、JavaScript，无运行时依赖、无模型费用。
- 头像采用原创 SVG 字母头像，不代替真实照片；名字 Zhong，介绍及兴趣仅采用需求中的事实。
- 首屏左侧自我介绍，右侧数字分身；下方展示个人方向、三项近况和网站作品。
- 数字分身为明确标注的资料问答原型，依据固定资料匹配问题。支持快捷问题、输入发送、清空、未知问题引导；不声称已接入大模型，不编造作品或邮箱。
- 联系入口仅采用用户指定仓库所属的 GitHub 账号 Rapeter。
- 对话仅存在页面内存中，刷新清除，不发送到服务器。
- 响应式覆盖 360px 至桌面；支持键盘、输入法、减少动态效果偏好。

## 视觉

背景 #f7f9fc，正文 #172126，次要文字 #5e6b73，浅蓝 #eaf3ff，薄荷绿 #e8f5ef，强调绿 #17664c。使用本地系统中文字体和 Segoe UI，避免外部字体依赖。以首屏的大号自我介绍和可立即使用的聊天为主，留白与细线辅助阅读。

## 验收

三类常见问题可回答；未知事实明确告知未提供；空白消息不可发送；用户输入以纯文本显示；清空后回到初始会话；手机无横向溢出；静态构建只输出网页文件。

未来可增加真实头像、经确认的作品和联系信息，并通过服务端代理接入模型。
