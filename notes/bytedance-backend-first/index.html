Q05｜矿区作业系统接入 Agent 解决什么问题 #

问题／对话入口（概括）： 在矿区作业系统使用 Agent，主要解决什么问题？

实际回答与对话过程（概括）： 解释多矿区重复接入 API 的问题：整理接口、使用 OpenAPI 定义、经生成流程封装为 MCP 工具以便复用，最终提高流程效率、减少重复开发。

Q06｜重复开发工作量下降 50% 如何计算 #

问题／对话入口（概括）： 简历写重复开发工作量下降 50%，这个数怎么来的？

实际回答与对话过程（概括）： 用新矿区接入举例，说原来约两到三个人、一天完成，现在约一个人一天完成，按工作时间估算下降约 50%；面试官确认是研发效率口径，你回答是。原句中人数与时长关系有口语含混。

Q07｜HTTPS 反向代理解决了什么连通问题 #

问题／对话入口（概括）： 反向代理相关问题的背景、痛点和具体解决过程是什么？

实际回答与对话过程（概括）： 回答 Agent 不直连业务系统，而经统一 HTTPS 代理按矿区路由到内网接口，涉及证书校验和请求头透传。随后主要展开设备故障 API 联调：核对 OpenAPI 契约、参数和地址，用脚本提交固定测试数据，不只检查 HTTP 200，还通过查询接口按设备、时间、矿区和 ID 反查业务记录。

Q08｜单笔流程从 15 分钟降到 4 分钟 #

问题／对话入口（概括）： 原来为什么要 15 分钟？为什么做完以后是 4 分钟？

实际回答与对话过程（概括）： 解释原来人工跨系统操作约 15 分钟，现在人工主要做审批，端到端约 4 分钟，减少约 73%；并强调不是单个系统调用耗时。

Q09｜Token 成本异常如何定位和治理 #

问题／对话入口（概括）： 成本优化怎么做？

实际回答与对话过程（概括）： 说查看 token usage 发现某矿区夜间巡检消耗异常，通过 Trace 关联模型与工具，发现设备查询工具短时间被多轮调用；区分工具内部超时重试造成业务请求放大，与 Agent 多轮调用、上下文回填带来的 Token 增长。提出相同参数复用结果、矿区预算、高峰限流，以及补齐矿区和工具标签。工具准确名称未可靠确认。

Q10｜除了减少调用，还有什么降成本方法 #

实际回答与对话过程（概括）： 先回答尽量使用单 Agent、减少重试、限流和最大步数。面试官提示模型方向后，回答规划／路由使用较强模型，执行步骤使用较小模型，并把收益描述成 Token 消耗可能更少。
